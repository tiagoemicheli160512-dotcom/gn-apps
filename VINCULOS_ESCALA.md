# Vincular os logins à escala — o que falta

O bloqueio de folga e férias só alcança um login depois que ele estiver ligado a uma linha
da escala. **Enquanto ninguém for vinculado, nada muda pra ninguém** — o app continua
abrindo normalmente pra todo mundo.

Onde se faz: **app Usuários → Editar → "Funcionário na escala"**. A lista mostra, embaixo de
cada pessoa, se ela já tem vínculo ou não.

Quem é **GERAL** (supervisor, mestre, RH, compras, administrador, manutenção) não aparece
nessa conta — não tem escala, então nunca é bloqueado.
